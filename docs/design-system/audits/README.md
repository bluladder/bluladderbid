# Design audit records

Do not begin a broad audit merely because this directory exists.

When an audit is authorized:

1. copy the Skill's `assets/audit-report-template.md`;
2. name the report `YYYY-MM-DD-<product>-<scope>.md`;
3. record repository commit, environment, routes, journeys, viewports, and input methods;
4. separate observed browser evidence from code-only evidence;
5. redact customer data and sensitive internal details;
6. keep screenshots in an approved artifact location and link them;
7. record untested areas and confidence;
8. require an approved Design Director specification before broad implementation.
